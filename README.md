# cute-baby-photo-illustration

把宝宝、儿童和亲子照片转换成温暖的彩铅蜡笔涂鸦插画的可复用 Agent Skill。

[English](README.en.md) · [安装说明](INSTALL.md) · [提示词](references/prompts.md) · [校验方法](VALIDATION.md)

## 它能做什么

保留人物辨识度、表情、服装、姿势与关键道具，通过细腻彩铅面部、粗糙蜡笔轮廓、斜线腮红和纸底涂鸦形成统一风格。内置经典蜡笔、柔和彩铅、活泼涂鸦、简洁头像、成长海报五种预设。

**这是指令与执行流程，不是图像模型或独立软件。** 宿主已有可调用的图像编辑工具时，Agent 会按流程实际编辑照片并检查结果；没有工具时只能交付明确标注的提示词。安装 Skill 不会自动获得图片能力、API额度或外部账号，也不包含独立API客户端。

## 快速开始

1. 按 [安装说明](INSTALL.md) 将完整文件夹安装到宿主的技能目录。
2. 上传要转换的照片。第三方插画可作为可选风格参考，需明确区分输入角色。
3. 输入：`使用 cute-baby-photo-illustration，把这张宝宝照片转成 classic-crayon 手绘插画，保留原表情和衣服。`

无需安装也可把 `SKILL.md` 与相关参考文档交给支持图片编辑的助手阅读；这只是本次会话使用，不等于全局安装。

## 预设

| 预设 | 效果 |
|---|---|
| `classic-crayon` | 默认：细腻面部、重蜡笔轮廓、鲜亮点色 |
| `soft-pencil` | 柔和彩铅、奶油配色 |
| `playful-doodle` | 更明显颗粒与童趣装饰 |
| `avatar-clean` | 1:1头像、减少背景元素 |
| `milestone-poster` | 3:4纪念图、为指定文字留白 |

默认保留原图比例。用户指定构图、背景、文字时优先遵守用户要求；工具支持的规格决定实际输出。详见 [风格预设](references/style-presets.md)。
